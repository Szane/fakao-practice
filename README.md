# 法考主观题机考模拟

界面照搬**国家统一法律职业资格考试计算机化考试模拟答题系统（主观题）**，用来自己练主观题作答。在此之上加了原系统没有的三件事：**历史快照**、**字数统计**、**保存到文件**。

**题库是空的**——默认给 3 道空白题，题目材料自己粘进去就行。内置示例题已经去掉了。

## 文件

| 文件 | 说明 |
| --- | --- |
| `法考主观题机考模拟.html` | **双击即用**，单文件、零依赖、可离线（目标浏览器：Chrome） |
| `app.html` | 源文件（片段形式，发布网页用） |
| `build.mjs` | 由 `app.html` 生成上面那个完整单文件 |
| `check.mjs` | 语法检查 + 检查 JS 引用的 id 是否存在 |
| `smoke.mjs` | 用无头 Chrome 跑 60 项交互测试 |
| `shot.mjs` | 截图，用来和参照界面对比 |

```powershell
node build.mjs    # 改完 app.html 后重新构建
node check.mjs    # 快速自检
node smoke.mjs    # 完整交互测试
node shot.mjs     # 截图到 _shot/mine.png
```

## 界面

完全按官方机考系统还原：蓝色顶栏（考生信息／系统标题／答题用时／交卷）、左侧可收起的答题卡栏（题号格、说明、法律法规汇编）、材料在上答题在下、问题标签条、`撤销/恢复/复制/剪切/粘贴/放大窗口`、红色「已输入字数为: N」、底部 `☐标记 上一题/上一问/下一问/下一题`。

配色是从参考截图里**逐像素采样**出来的，不是目测：

| 元素 | 色值 |
| --- | --- |
| 顶栏 / 面板标题条 | `#61ABE8` |
| 左栏、工具条底 | `#DDEBF6` |
| 材料区 | `#F9FDFF` |
| 答题区 | `#EAF4FB` |
| 激活的问题标签 | `#FFBB00` |
| 说明 / 字数红字 | `#FA0000` |
| 按钮边框 | `#98AEE8` |

材料用宋体，界面用微软雅黑 —— 和原系统一致。

**刻意只做一套亮色**：考场系统不会跟随系统深色模式，所以不写 `prefers-color-scheme`。顶栏的「切换风格」提供 默认蓝／护眼绿／淡灰 三套配色。

## 作答单位是「问」

这是和常见做法最不一样的地方，也是照抄原系统的结果：

- 一道**题**（如「第2题 刑法」）下有多个**问**，每个问是独立的作答单位
- 每问有自己的文本框、字数、历史快照、标记状态
- 答题卡上的题号格显示该题**所有问的合计**，题号旁的 `*` 表示该题还有问没作答
- `上一问 / 下一问` 跨题连续跳转：在第2题问题1 按「上一问」会回到第1题的最后一问

题号格上的符号沿用原系统约定：`*` = 未作答，`?` = 做过标记。

## 三个附加功能

**历史快照**
- 每满 60 秒或内容变化 300 字自动存一版，也可 `Ctrl+S` 手动存；按**问**独立记录
- 时间线显示每版时间、字数、较上一版的增减
- 点开是**字符级差异高亮**（绿底新增／红底删除），长段落自动折叠
- 恢复任意一版前会先把当前内容存成「恢复前」快照，所以恢复本身也能反悔
- 每问最多 60 版，另有 120 万字全局预算，不会撑爆浏览器存储

**字数统计**
- 按**非空白字符**计（含标点），与国内考试口径一致
- 「已输入字数为: N」是当前问的（红字，同原系统）；旁边灰字补上本题合计与建议字数
- 统计面板：全文总计、汉字／标点／段落拆分、各题横向条形图（红刻度＝建议字数）、各问明细、用时与写作速度

**保存到文件**
- `Ctrl+S` 存快照并写入已绑定文件。首次弹一次「另存为」并记住，之后直接覆盖，不再打断
- 绑定后每 30 秒自动写入（有改动才写，可关；可改成只写当前题）
- 左栏「保存到文件」显示当前绑定状态，点击可更换或解除
- 手动导出支持 `.txt` / `.md` / `.json`，可选「本题历史／全部题目」
- 「完整备份」（JSON）含题库、答卷与全部历史，可在另一台设备导入还原

## 数据

全部存在本机浏览器 `localStorage`，不上传任何服务器。换浏览器或清空站点数据会丢，重要答卷请用「保存完整备份」导出。

## 出题

打开就是 3 道空白题，材料区会提示。三种加法：

**1. 编辑当前题** —— 材料区右上角 `编辑本题`（双击题目标题也行）：

| 字段 | 怎么写 |
| --- | --- |
| 科目名 | 显示成「2、刑法」 |
| 材料 | 直接粘。**空行分段**；行首加 `## ` 会渲染成 `[小标题]` |
| 问题 | **一行一问**，有几行就有几个「问题N」标签 |
| 答题要求 | 一行一条，渲染在材料末尾的 `[答题要求]` |
| 参考法条 | 一行一条，点左栏「法律法规汇编」查看 |

**2. 加一道新题** —— 左栏 `+ 新建题目`，建完直接弹编辑框。同一对话框里有 `删除本题`。

**3. 整套导入** —— 设置 →「导入题库 / 答卷」，粘 JSON（完整备份的格式）。

题目和作答都存在浏览器里；「保存完整备份」出来的 JSON 换台电脑导回去就能接着练。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `Ctrl/⌘ + S` | 存快照 + 写入已绑定文件 |
| `Alt + ← / →` | 上一题 / 下一题 |
| `Alt + ↑ / ↓` | 上一问 / 下一问 |
| `Alt + M` | 标记 / 取消标记本问 |
| `Esc` | 关闭面板，或退出放大窗口 |

## 已知取舍

- 参照界面材料区右上角那排划词批注工具（高亮／注音／目录／收藏…）没有做，只保留了 `标记文字 / 取消标记` 对应高亮
- 放大窗口是页面内放大（铺满视口），不是新开窗口
- 「切换风格」原系统的行为未知，这里实现为切换配色（默认蓝／护眼绿／淡灰）
- 只保证 Chrome
- 左栏「说明」那三行沿用了原系统的文案（`*` 未作答、`?` 做过标记），是照抄不是自创，字号压得比较小
